# OSNOVA PLAN — тестовый стенд U07

Отдельная браузерная сборка для проверки анкеты на реальном iPhone/Safari.

Адрес: https://alexkhramtsov2001.github.io/osnova-plan-preview/plan.html

В этом репозитории только проверенная статическая сборка: index.html/plan.html, пять JS/CSS-ресурсов (включая настоящий Worker), .nojekyll, лицензии и release.json с SHA-256 файлов. Исходники, тесты, журналы, резервные копии, пользовательские проекты и source maps не опубликованы. B12 и тестовые порты не являются входом стенда. Основной сайт OSNOVA не изменяется.

Вычисления выполняются в браузере. Ввод и принятый план живут только в памяти вкладки: обновление страницы их сбрасывает. Сохранения и PDF ещё не реализованы. Схема концептуальная, не строительный проект; проверки здания и мебели не завершены.

## Публикация и обновления

Первый отдельный стенд разрешён владельцем 04.11.2026. GitHub Pages публикует корень main; .nojekyll отключает обработку Jekyll. Новые снимки сборки — только после согласования контрольной точки с владельцем. CI основного сайта не используется. Для отката нужен отдельный согласованный revert на ранее проверенный снимок, без force push.

Источник — локальная контрольная точка U07; production-сборка Vite с base ./ и настоящим браузерным Worker. Хеш исходного контрольного архива и хеши опубликованных файлов находятся в release.json. Зависимости React/React DOM/Scheduler и выбранный код OpenCalque — в THIRD_PARTY_NOTICES.md; общая лицензия на оригинальный код проекта этим не назначается.

## M1: проверка владельцем

На настоящем iPhone в Safari: открыть plan.html; проверить анкету, клавиатуру, ввод 120/44/3,0 и технологию каркас, ошибку 120,05, исправление, переходы Дом → Комнаты → Вход → Результат → Назад; проверить добавление/удаление комнат, цели, кнопку Далее и горизонтальную прокрутку. Сообщить модель iPhone, iOS/Safari и результат. Обновлять страницу только после проверки возврата: данные пока не сохраняются. M1 и Q01 до ответа владельца остаются pending.
