# OSNOVA PLAN — тестовый стенд Q01.1

Два готовых примера и ручная анкета для проверки на iPhone.

- [80 м², 1 санузел](https://alexkhramtsov2001.github.io/osnova-plan-preview/demo-80.html)
- [120 м², 2 санузла](https://alexkhramtsov2001.github.io/osnova-plan-preview/demo-120.html)
- [Ручная анкета](https://alexkhramtsov2001.github.io/osnova-plan-preview/plan.html)

Демо запускается кнопкой «Создать чертёж» и использует расширенный режим до 30 секунд. Ручная анкета по умолчанию использует обычный режим до 10 секунд. Принятый план и ввод сохраняются до закрытия или обновления вкладки. Чертёж концептуальный.

Для проверки на телефоне укажите модель iPhone, версию iOS/Safari, адрес и результат. На демо проверьте запуск, принятие, отмену повтора и масштабирование. В ручной анкете проверьте клавиатуру, ввод, навигацию и подсказки ошибок.

Цель сборки — iOS/Safari 16.4. Результат на этой версии и проверка M1 на устройстве фиксируются отдельно. Сведения о сборке — в [release.json](release.json), лицензии — в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
