# OSNOVA PLAN — пакет проверки Q01.2

- `demo-120.html` — дом 12 × 10 м. Вариант «Раздельный семейный и гостевой с душем» показывает семейную ванную, отдельный туалет и гостевой санузел с душем. Выберите состав, нажмите «Создать чертёж», изучите смежность помещений, площадь холла и длины маршрутов. Примите подходящий план, запустите повтор и отмените его. Принятый план должен сохраниться в этой вкладке.
- `demo-80.html` — отдельная страница дома 10 × 8 м с одним совмещённым санузлом.
- `plan.html` — ручной мастер. Проверьте ввод, экранную клавиатуру, навигацию и ошибки полей.

После проверки запишите модель iPhone, версию iOS/Safari, адрес и наблюдения. Укажите состав, режим, исход поиска и поведение масштабирования. Изменение состава или повторный поиск не должны самостоятельно заменять принятый план. После обновления страницы вкладка начинает новый сеанс.

План концептуальный. Целевая версия сборки — iOS/Safari 16.4. Подтверждение на устройстве фиксируется отдельно. [Манифест](release.json) · [Лицензии](THIRD_PARTY_NOTICES.md).
